# Politica de privacidade - SEO

Documento base para revisao juridica antes de producao.

## Responsavel pelo tratamento

A entidade cliente que utiliza o SEO para gerir dados operacionais, financeiros, clientes, fornecedores e inventario atua como responsavel pelo tratamento. O fornecedor tecnico do SEO deve ser tratado como subcontratante quando processa dados por conta dessa entidade.

## Dados tratados

O SEO pode tratar:

- dados de utilizadores: nome, email, perfil, permissoes e registos de acesso;
- dados comerciais: clientes, fornecedores, plataformas, documentos e valores;
- dados operacionais: produtos, referencias, stock, margens e movimentos;
- dados de auditoria: data, acao, resultado e identificador pseudonimizado do utilizador.

## Finalidades

- autenticar utilizadores;
- processar ficheiros carregados pela empresa;
- gerar dashboards e relatorios;
- sugerir classificacoes SNC;
- auditar acoes sensiveis;
- melhorar eficiencia operacional.

## Base juridica

A base juridica deve ser definida pela empresa com apoio juridico. Podera incluir execucao de contrato, cumprimento de obrigacoes legais, interesse legitimo e consentimento quando aplicavel.

## Conservacao

Os dados devem ser conservados apenas pelo periodo necessario para a finalidade definida. Antes de producao, devem ser aprovados prazos para:

- ficheiros importados;
- relatorios gerados;
- logs de auditoria;
- contas inativas;
- pedidos de apagamento.

## Segurança

Medidas minimas:

- HTTPS obrigatorio;
- palavras-passe com hash forte;
- tokens com expiracao;
- permissoes por perfil;
- encriptacao em repouso;
- backups protegidos;
- auditoria pseudonimizada;
- principio do menor privilegio;
- segregacao entre dados de empresas.

## Direitos dos titulares

Devem existir procedimentos para acesso, retificacao, apagamento, limitacao, oposicao e portabilidade, quando aplicavel.

## Subcontratantes

Antes de producao, devem ser identificados fornecedores de alojamento, email, IA, armazenamento, monitorizacao e backups. Cada fornecedor deve ter acordo de tratamento de dados quando aplicavel.

## IA e decisao humana

As recomendacoes da IA sao apoio operacional. Classificacoes contabilisticas, decisoes fiscais e documentos oficiais exigem validacao humana por profissional competente.
